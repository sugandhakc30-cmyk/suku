# Sugandha Tech — Next.js + TypeScript + Tailwind

Tech Reviews. Best Picks. Smart Choices.

This repository is a starter scaffold for Sugandha Tech — a technology reviews and buying-guides publication built with Next.js (App Router), TypeScript and Tailwind CSS.

Quick start:
1. Install dependencies: `npm install`
2. Run dev server: `npm run dev`
3. Build for production: `npm run build`
4. Start production server: `npm run start`

Project structure:
- app/ — Next.js App Router pages (home, reviews, guides, comparisons, best, news, legal pages)
- components/ — reusable UI components
- data/ — demo content (articles, products, categories)
- lib/ — small helpers (seo, search)
- public/ — images, favicon
- styles/ — global CSS

This scaffold is built to be edited. Replace demo content in data/ with your editorial content and configure affiliate links in product data.
